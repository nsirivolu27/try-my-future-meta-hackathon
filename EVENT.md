# Meta event workspace

This repository is the dedicated Meta event submission workspace for **Try My Future**.

It starts from the working app at `nsirivolu27/try-my-future`, commit `a64fa34edb85d6cdf6248058419ed415bfc0a7e9`, copied October 27, 2026. The original app repository remains separate.

- App overview and build instructions: [README.md](README.md)
- Pitch, demo flow and submission draft: [docs/SUBMISSION.md](docs/SUBMISSION.md)
- Tested behavior and physical-device checklist: [docs/VALIDATION.md](docs/VALIDATION.md)
- Nationwide directory and provenance: [data/README.md](data/README.md)

The initial focus is Android and Ray-Ban Meta Gen 2, while retaining hardware-independent audio mode and the nationwide campus experience.

Before submission, verify the event's exact name, rules, deadline, SDK requirements and required repository visibility from the actual invitation. Test the Meta adapter on physical glasses and record only demonstrated behavior. The current prototype does not perform visual landmark recognition or call a generative model.

This repository is private. No event submission has been sent.
